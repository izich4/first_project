# Student Deadline Bot

Это мой семестровый проект по предмету «Введение в профессиональную деятельность». Я решил разработать Telegram-бота на языке Python, который помогает студентам следить за сроками сдачи лабораторных, практических и курсовых работ, чтобы не пропускать важные дедлайны во время учебы.

Бот создается с помощью библиотеки pyTelegramBotAPI (telebot). В него можно добавлять новые учебные задачи с указанием предмета и даты сдачи, просматривать список всех актуальных долгов и удалять уже сданные работы. Чтобы список задач не пропадал после выключения компьютера, все данные сохраняются в файл формата JSON, а для автоматического подсчета оставшихся до сдачи дней используется встроенный модуль datetime.

Разработка проекта идет постепенно от простого к сложному. Сначала подготавливается репозиторий и создается базовая версия бота, которая умеет запускаться и отвечать на простые текстовые команды приветствия и помощи. Затем к боту подключается кнопочное меню в Telegram и настраивается сохранение задач в файл. После этого добавляется пошаговый диалог для ввода новой задачи, проверка правильности введенной даты и расчет оставшегося времени. На заключительном этапе реализуется удаление выполненных заданий, проводится проверка кода на ошибки и оформляется итоговая инструкция по запуску программы.
